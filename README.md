# Ask Anything Hub

회사에서 직원들을 대상으로 CEO 타운홀 미팅을 준비하고 있는데 사전 질문을 직원들에게 받을 예정이야. 대부분 HR관련된 질문들이 많을텐데, 실시간으로 질문을 받을 수 있는 페이지를 하나 만들어줄래? 실시간으로 익명 질문을 남기고 댓글이나 좋아요도 익명으로 남길 수 있었으면 하고, HR이나 회사 방향성, 제도 등에 대하여 다양한 카테고리로 질문을 남길 수 있었으면 좋겠는데, 별도 로그인을 하지 않고 링크로만 접속 권한이 있었으면 좋겠고, 지난번에 CEO 타운홀 미팅 미답변 질문들을 올렸던 페이지에서 만들 때 활용한 회사 CI와 BI를 마찬가지로 넣어주면 좋겠어.
